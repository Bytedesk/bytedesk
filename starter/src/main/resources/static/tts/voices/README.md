# TTS Voice Preview Assets

These preview files are downloaded from Aliyun CosyVoice official documentation for internal testing and voice selection UX.

Source page:
<https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list>

Notes:

- Files are used for local preview in admin TTS voice selector.
- Only a compact set of major preview voices is kept in this directory to control repository size.
- For full voice audition and updates, use the official list: <https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list>.
- If upstream URLs change, re-download and update the catalog `sourceUrl` fields.
