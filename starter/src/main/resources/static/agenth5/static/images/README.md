# 静态资源说明

本目录需要准备以下图片资源：

## TabBar 图标 (static/images/tab/)

以下图标需要准备两套：普通状态和选中状态

- `chat.png` / `chat-active.png` - 会话图标 (建议尺寸: 81x81px)
- `leave.png` / `leave-active.png` - 留言图标 (建议尺寸: 81x81px)
- `ticket.png` / `ticket-active.png` - 工单图标 (建议尺寸: 81x81px)
- `workspace.png` / `workspace-active.png` - 工作台图标 (建议尺寸: 81x81px)
- `mine.png` / `mine-active.png` - 我的图标 (建议尺寸: 81x81px)

## 其他图片

- `default-avatar.png` - 默认头像 (建议尺寸: 200x200px)
- `logo.png` - 应用 Logo (建议尺寸: 200x200px)

## 图标设计建议

1. **TabBar 图标**:
   - 使用线性图标风格
   - 线条粗细适中，建议 2-3px
   - 圆角处理，保持一致性
   - 普通状态使用灰色 (#999999)
   - 选中状态使用主题色 (#007AFF)

2. **默认头像**:
   - 简洁的用户图标
   - 使用浅灰色背景
   - 居中显示用户剪影

3. **Logo**:
   - 简洁明了
   - 易于识别
   - 支持圆角显示

## 临时使用

在开发阶段，可以使用以下方式临时替代：

1. 使用在线图标库（如 iconfont）
2. 使用 Emoji 表情符号
3. 使用纯色占位图
4. 使用设计工具生成临时图标
